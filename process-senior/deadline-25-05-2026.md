Plan 22/5 Native AOT Trade-offs
Lý thuyết:
Native AOT: không có JIT, không có reflection by default, trimming aggressively
Trade-offs: startup ↓ 10x, memory ↓ ~50%, cold start → fast; nhưng: larger binary, no dynamic code
ASP.NET Core AOT: Minimal APIs compatible, Controller-based không fully supported
JSON source generator bắt buộc (không dùng reflection-based JsonSerializer)
